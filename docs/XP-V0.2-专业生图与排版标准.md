# XP Visual Production V0.2｜专业美妆图文制作与审核标准

> 原则：**不是“AI 一次生成完整海报”，而是“导演分镜 → 摄影底片 → 真实商品素材 → 稳定文字排版 → 可追踪人工审核”。**

## 为什么以前生成的图不专业

1. 将真实商品包装、固定人物、复杂中文排版和审美构图一起交给单次图像生成，极容易出现商品结构错误、人物漂移、错字。
2. 五张图只换场景、不换镜头语言，导致缺少编辑节奏。
3. 没有高质量商品及人物参考，靠“写实/高级”形容词代替真实可核验的视觉依据。
4. 没有摄影底片和文字的独立返修，导致一处错字就得全部重生成。
5. 只有主观总分，没有产品、人物、规格和版式的硬性门禁。

## V0.2 实施的6个工位

**A｜素材取证：** 商品品牌、精确SKU、色号、容量、正反面包装、可公开使用的准确商品图。仅有官方详情页链接不意味着获得合法的高清资产。受版权限制或未公开的素材不进入公开仓库。人物锚点如使用真人原图须获授权，私密参考应当放在专门的私有存储。

**B｜五页独立分镜：** `P01 封面 EDITORIAL_HERO`、`P02 真实商品 TRUE_PRODUCT_PACKSHOT`、`P03 质感/场景 MATERIAL_IN_USE`、`P04 信息/证据 EVIDENCE_EDITORIAL`、`P05 收束 CLOSING_STILL_LIFE`。每页不同摄影焦段、光线组织、视距、留白和信息密度，不能五页模板化重复。

**C｜背景摄影：** 图像模型只生成可信的背景或持有真实参考的人物画面。锁定统一光线方向与色彩范围；自然毛孔、真实织物/玻璃/金属质感；拒绝塑料光泽、假神光、过度HDR。若没有真实商品视觉参考，**只生成背景底片**。

**D｜商品合成：** 官方/自有授权商品图严格保持原包装与Logo，不以模型“凭记忆重画”真实商品。当前 V0.2 尚未提供智能抠图与透明商品图精确合成器，需要人工或外部工具完成此步；不得伪称已经完成。

**E｜文字后期：** 用 Canvas 排版将已经校对的中文标题、正文摘要和页码叠加在本地底片之上，形成1086×1448的无损PNG或高质量JPG（质量参数0.94）。已实现5种布局，不依赖模型直接绘制汉字。客户端底片须至少650×850，正式成品要求1086×1448。图片上传时浏览器会检查实际解码尺寸；GitHub服务端再按文件头检查尺寸。尺寸合规不代表美学或产品真实性合规。

**F｜审核与重修：** 用户为每张图片逐项确认8项；缺少参考材料不可勾选PASS。每页最多3轮返修，超过进入BLOCKED并请求人工裁决。已通过页冻结；修改商品信息撤销旧审核，修改本页文字撤销本页审核。

## 八项不可跳过的审核

| 硬项 | 确认内容 |
|---|---|
| 商品身份 | 品牌、包装、规格、色号与核验资料一致 |
| 商品保真 | 商品资产没有被模型改动或冒用 |
| 人物一致性 | 有人物时外貌、小痣、方向正确，没人物则明确不适用 |
| 文案真实性 | 没有虚构个人体验、疗效、来源 |
| 摄影构图 | 景深、色彩、光线、主体清晰度、页间变化符合分镜 |
| 文字排版 | 汉字、留白、字号、行距、遮挡全部合格 |
| 技术参数 | 1086×1448像素、3:4、清晰 |
| 版权隐私 | 素材来源合法，真人和私密资料不泄露 |

**注意：这些是人工确认按钮，不是AI识图测量。** 最终是否专业取决于生成原片质量、商品资产、设计审美与严格审核。工具只阻止明显遗漏，不能替代专业摄影师与设计师的品控判断。

## APP中已可使用的功能

1. 「文案」页每张图下按「生成专业视觉指令」，得到该页独立的摄影指令及相关资产风险提示。
2. 用你选择的模型、真实商品与人物参考生成或编辑**不带中文文字的底片**；如果没有原商品参考只能生成环境底片。
3. 「图片」页按「本地排版并下载PNG」，手机选择获得授权的底片，浏览器本地生成1086×1448带文字JPG/PNG并下载，无需上传底片至服务端。
4. 实际用手机查看成品图，检查人物和商品是否被裁切、标题是否遮挡、商品是否真实、肤质是否自然。
5. 选择「上传」将经过审核的成品写入GitHub（公开仓库会公开，先确认素材授权和隐私）。
6. 「审核」页勾选八项质量确认后才能设置PASS；检查不合格则填REWORK具体问题。

## 尚未打通的能力

- 不具备内置AI图片生成接口或图像编辑模型调用。按提示词自动生图需要后续增加独立模型服务与收费控制。
- 现在的后期是文字版式与底片裁切，不是自动PS抠图、换背景、真实商品自动贴合、PS级图层编辑。
- 底片裁切目前按中心优先；复杂人像主体位置可能被裁切，需要人工选取合适底片与再次检查。
- 尚无真实图片像素层面的自动文字溢出检测、产品真伪图像识别或 AI 视觉评分。
- UI、渲染器需要部署后在不同Android浏览器、中文字体和高密度屏幕上做实际可视化验收。
- 修改图片时，用户仍需对最终成品进行审查并保持平台合规。

## 后续建议的 V0.3 优先级

1. **受控AI图像编辑**：上传真实商品图并保持严格保真，生成可复用摄影底片。
2. **透明商品层/遮罩**：自动去背景但不重画包装、检测商品像素和比例变化。
3. **私人参考资产仓**：存放PERSONA-001授权锚点及原商品高分辨素材，避免公开GitHub隐私暴露。
4. **审美参考板和真实样本评测**：取用户满意和不满意的各10张建立视觉指标，持续进行A/B对比。
5. **视觉审核接口**：配合确定性像素尺寸、文字边界、OCR/参考对照检查，再由人工最终确认；成本可审计，失败只重做问题页。

**完成定义：五张在手机上细看依旧有真实可信的商品、摄影质感、准确中文和连续统一的品牌叙事，且100%有审核记录。**

## 导出大小说明

摄影底片加文字后，无损PNG可能明显超过3MB。上传到当前XP服务端仍限制单张3MB，故默认建议下载质量0.94的高清JPG用于工作台上传，PNG保留作无损本地档案。如果JPG仍超过3MB，需要在有质量预览的前提下合理压缩，不能只靠把文件后缀改名。工作台没有自动压缩或上传任意大图的功能。
