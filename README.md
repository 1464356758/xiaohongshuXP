- [20个GitHub开源项目逐项优缺点评估](research/2026-10-22-GitHub小红书开源项目20项调研.md)：明确开源许可、核心能力、适用场景、优势、局限、再利用建议。还单独标出7个许可/商业使用有风险的参考项目。
- [xiaohongshuXP V1 系统架构与阶段路线](design/XHS-XP-V1-系统架构与落地路线.md)：按移动端、GitHub任务状态、真实商品、美妆人物锚点、五页图文、质检、人工发布设计。

## 当前状态

**RESEARCH_COMPLETE / ARCHITECTURE_PROPOSED**。目前交付的是调研与架构草案，尚未开发、部署或测试软件，不宣称自动写图、自动发布已实现。

## 设计原则

1. GitHub维护任务、版本、事实证据和审核结果；每次写入后回读核实。
2. 内容创作优先质量、真实商品、人物/色号一致性和原创表达。
3. 手机端可查看当前进度、审稿、复制与导出；重大节点由用户确认。
4. 不默认启用全自动发布、批量评论或模拟真人互动，遵守小红书平台规则。
5. 第三方代码按对应许可证合规复用，先小规模实测再集成。
